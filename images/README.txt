Put club photos in this folder.

Then reference them from gallery.html like this:

    <img src="images/your-photo.jpg" alt="Describe the photo" loading="lazy">

Tips:
  - Use lowercase file names with dashes, e.g. spring-showcase-2026.jpg
  - Resize photos to about 1200 pixels wide before uploading so pages load fast.
  - Always fill in the alt="" text so screen readers can describe the photo.
